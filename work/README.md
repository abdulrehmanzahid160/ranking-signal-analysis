# Work

The `notebooks/` directory contains the capstone notebook and its numbered, reviewable Python modules:

- `00_schema_discovery.py` records metadata without exposing sample rows.
- `01_signal_features_audited.py` streams and aggregates leakage-separated features.
- `02_modeling.py` runs the grouped baseline, Ridge, tree, and stability comparison.
- `03_query_associations.py` keeps overlapping query-window findings descriptive.
- `04_analysis_outputs.py` generates public-safe aggregate reporting artifacts.
- `capstone_ranking_signal_analysis.ipynb` runs the full sequence interactively.

Content-level data outputs are ignored by Git.
